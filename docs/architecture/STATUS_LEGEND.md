# وسيلة إيضاح الحالات والألوان والأدلة (STATUS LEGEND)

> هذه الوثيقة تُعرّف المفردات المستخدمة في **كل** مخططات وجداول `docs/architecture/`.
> الهدف: منع الخلط بين «موجود في الكود» و«مُختبَر» و«يعمل في الإنتاج».

## 1) الألوان (ثلاث حالات فقط)

| اللون | الحالة | المعنى الدقيق |
|---|---|---|
| 🟢 **أخضر** | منجز ومثبت | الوظيفة موجودة **وتحقّقت بدليل** مناسب (كود / اختبار / إنتاج — حسب مستوى الدليل). |
| 🟠 **برتقالي** | قيد الإنجاز / جزئي | جزء من الوظيفة موجود، أو ينقصه استكمال، أو لم يكتمل التحقق التشغيلي منه. |
| 🔴 **أحمر** | متبقٍ / غير مثبت | الوظيفة المطلوبة لم تُنفَّذ، أو لا دليل كافٍ على إنجازها، أو تعتمد على إعداد خارجي غير مكتمل. |

**قيود إلزامية على الاستخدام:**
- ❌ لا يُستخدم الأخضر بمجرّد وجود ملف أو زر أو تبويب واجهة.
- ❌ لا يُستخدم الأحمر إذا كان هناك تنفيذ جزئي — يُستخدم البرتقالي عندئذ.
- ❌ لا يُستنتج أن نظاماً «غير موجود» لأنه لم يُعثر عليه؛ يُسجَّل «لم يُتحقق» صراحةً.

## 2) مستويات الدليل (Evidence Level)

| الرمز | المعنى |
|---|---|
| `CODE` | موجود في الكود المصدري (قراءة فعلية للملف). |
| `TEST` | يوجد اختبار مخصّص يجتاز، ويثبت السلوك. |
| `PRODUCTION` | تُحقّق منه فعلياً على `https://al-gharabi-ai.onrender.com` (استجابة حية). |
| `EXTERNAL` | يحتاج حساب/صلاحية/موافقة/إعداداً خارجياً (Meta/Google/TikTok…) لم يكتمل. |
| `UNVERIFIED` | لم يُتحقق منه بما يكفي. |

**قاعدة الفصل:** نجاح الاختبارات (`TEST`) **لا** يعني نجاح التشغيل الحقيقي (`PRODUCTION`).
تسجيل «مثبت» يستلزم ذكر مستوى الدليل صراحةً.

## 3) مفردات المعمارية الملزمة

- `Capability ≠ Connection ≠ Verification ≠ Delivery`
  القدرة المُعلنة ≠ وجود اتصال ≠ إثبات المزود ≠ التسليم الفعلي بمعرّف من المزود.
- `Knowledge ≠ Inference ≠ Hypothesis` و`Analysis ≠ Execution`.
- `Signal ≠ Lead ≠ Request ≠ Sale` (لا بيع بلا معرّف بيع حقيقي).
- العقل المركزي **يحلّل/يقرّر مقترحاً**؛ التنفيذ الخارجي يمرّ ببوابات المشروع
  (`EXTERNAL_ACTION` + تفويض/موافقة المالك) — لا تنفيذ صامت.

## 4) أسلوب الوثائق

- اللغة عربية، وأسماء الوحدات/الملفات/مسارات API تبقى **كما في الكود** بلا ترجمة.
- المخططات بصيغة Mermaid قابلة للتعديل، ومقسّمة لأجزاء واضحة.
- كل ادعاء يُسند إلى: مسار الملف، أو رقم commit، أو استجابة إنتاج حيّة.
