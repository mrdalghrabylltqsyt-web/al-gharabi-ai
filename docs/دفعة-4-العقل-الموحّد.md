# الدفعة 4/4 — العقل النهائي للنمو التجاري والتعلّم والتحسين الذاتي

## الغاية

دمج الدفعات 1–3 في **عقل تجاري مركزي واحد** (لا عقل تسويق منفصل ولا عقل بيع منفصل ولا
عقل منصة). الغاية العليا الوحيدة: **زيادة المبيعات الحقيقية الموثّقة، وزيادة الربح
الحقيقي الموثّق حين تتوفّر بيانات تكلفة موثوقة.** كل ما عدا ذلك قدرات مساندة.

## الوحدات الجديدة (`engine/brain/commercial/`)

| الوحدة | الدور |

| `strategy.ts` | توصيات مفسّرة + أولوية فرص + أهداف + شرح قرار |

| `routes.ts` | مسارات القراءة (Owner للحالة الكاملة) |

## الفصل المعرفي الملزم

`FACT ≠ OBSERVATION ≠ DERIVED_KNOWLEDGE ≠ HYPOTHESIS ≠ LEARNING ≠ RECOMMENDATION ≠ DECISION ≠ RESULT`

ولا يتحوّل قول AI أو بحث خارجي إلى حقيقة تجارية بلا تحقّق داخلي.

## المسارات (قراءة/تحليل/اقتراح فقط)

- `GET /api/agent/brain/commercial/state` (owner): الحالة الكاملة.
- `GET /api/agent/brain/commercial/summary`: ملخّص خفيف بلا بيانات عملاء.
- `GET /api/agent/brain/commercial/command-center` (owner): مركز القيادة.
- `GET /api/agent/brain/commercial/owner-control` (owner): ماذا يعرف/تعلّم/يراقب/اكتشف/يوصي/يتوقّع/حدث/تغيّر/فشل/يحتاج موافقة/سيختبر/يقترح.
- `GET /api/agent/brain/commercial/capabilities` (owner): تطوّر القدرات من أدلة.
- `GET /api/agent/brain/commercial/health`: صحة النظام.
- `GET /api/agent/brain/commercial/operating-loop`: دورة التشغيل + الأسئلة.

`/api/health.commercialBrain` يعرض ملخّصاً بلا سرّ (الإصدار، الغاية، توفّر المبيعات/الإيراد/الربح، حرس الربح، عدّ القدرات، الصحة).

## الحمايات (مُختبرة)

- لا بيع/إيراد/ربح مُخترع؛ الغائب `null` لا صفر، والربح لا يُحسب بلا تكلفة موثوقة.
- المقاييس الوهمية (مشاهدات/إعجابات/متابعون/وصول) لا تُعتمد هدفاً للتحسين.
- لا فائز تجربة بلا عيّنة وفرق كافيين؛ ولا ادّعاء تحسّن بلا دليل ومدّة.
- لا سببية حملة→بيع بلا سلسلة معرّفات موثوقة (وإلا `UNCERTAIN`/`NOT_ATTRIBUTABLE`).
- الاستفسار لا يصبح بيعاً؛ لا مشتري بلا معرّف بيع حقيقي.
- لا توسيع سلطة صامت؛ الإجراءات عالية الخطورة تتطلب موافقة المالك.
- التحسين الذاتي **اقتراح فقط**؛ لا نشر كود بلا اختبار/تدقيق/فحص أمني/موافقة.
- منع المساس بالمصادقة/التشفير/الأسرار/التعافي/الحقيقة التجارية الإنتاجية.
