# دفعة 3/4 — العقل المركزي للمبيعات الرقمية (قناة بيع ثانية)

## الهدف
تحويل العقل التجاري المتصل (دفعة 1) وعقل التسويق والطلب (دفعة 2) إلى **مدير مبيعات رقمي**
يجعل الجانب الرقمي **قناة بيع حقيقية ثانية** بجانب المعرض الفيزيائي — لا مُولّد محتوى.
السؤال المركزي ينتقل من «كيف أنشر؟» إلى «كيف أحوّل التفاعل إلى بيع موثّق؟».

## الفصل الصريح (قاعدة حاكمة)
```
Capability ≠ Connection ≠ Verification ≠ Delivery
Signal ≠ Lead ≠ Request ≠ Sale
Reach ≠ Interest ≠ Inquiry ≠ Lead ≠ Verified Sale
```
لا يُرقّى أي شيء إلى مرتبة أعلى بلا دليل: إشارة الشراء ليست بيعاً، والاستفسار ليس بيعاً،
و`VERIFIED_SALE` لا يقع إلا بمعرّف بيع حقيقي من سجل المبيعات.
